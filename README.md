# cpt

## 概要
cptは多倍長整数・多倍長浮動小数点による数式計算，LaTeX風の\sum, \prod，ユーザー定義関数，スコープ付き変数，論理・比較・三項演算などをサポートする数式処理系です．

## 特徴
- 多倍長整数・多倍長浮動小数点による計算
- 変数宣言・スコープ管理
- ユーザー定義関数（再帰可）
- 組み込み関数（print, abs, log, 三角関数, 累積和/積 など）
- LaTeX風の\sum, \prod, \log記法
- 論理演算・比較演算・三項演算子
- セミコロン区切りで複数式を記述可能
- 標準入力・ファイル入力・パイプ入力対応

## 動作環境・依存
- C++23 以降
- Boost.Multiprecision ライブラリ

## 使い方

cptはコマンドライン引数、**標準入力**、または`-f`で指定したファイルから数式（ソースコード）を読み込みます。

### コマンドラインオプション

- `cpt 数式`：数式を直接評価します。複数の引数に分けた数式は空白で結合されます。
- `-f ファイル名1 [ファイル名2 ...]`：ファイルを順に読み込みます。
- `-p 桁数`／`--precision 桁数`：浮動小数点数の**表示桁数**を指定します。計算内部の精度は変更しません。
- `--ast`：評価せずに抽象構文木をJSON形式で表示します。

`-f`とコマンドライン上の数式は併用できません。`-p`／`--precision`は、直接評価・ファイル入力・標準入力のいずれにも指定できます。

数式にはバックスラッシュを含む名前があるため、シェルから渡す場合は通常、単引用符で囲みます。

### 入力例

```sh
# 直接評価
./build/cpt '1 + 2 * 3'

# パイプ入力
echo '1 / 3' | ./build/cpt

# 表示桁数を指定
./build/cpt -p 20 '1 / 3'

# ファイル入力
./build/cpt -f sample.cpt

# ASTの表示
./build/cpt --ast '1 + 2 * 3'
```

標準入力で対話的に使用する場合は、入力の最後に`exit`を入力します。

```text
./build/cpt
def fib(n) {
  n <= 1 ? n : fib(n - 1) + fib(n - 2)
}
fib(10)
exit
```

`\input()`と`\read()`は標準入力から1行を読み込みます。直接評価では数式を標準入力から読み込まないため、次のように標準入力をそのまま`\input()`へ渡せます。

```sh
echo '42' | ./build/cpt '\input()'
```

### 評価と出力

ソースは上から順番に評価され、最後に評価された式の値が標準出力へ表示されます。`let`による宣言は初期値を評価してその値を返すため、最後の文が`let x = 10`なら`10`が表示されます。値が`void`の式は自動表示されません。

`\print(expr, ...)`は引数をその場で1行ずつ表示し、表示した引数の個数を戻り値にします。そのため、最後の式を`\print()`にすると、個数も最後に表示されます。

```text
\print(10, 20)
```

```text
10
20
2
```

## 言語仕様

### コメント・区切り

- `#`から行末まではコメントです。
- 文は主に`;`で区切ります。改行は空白として扱われます。
- 関数の引数、行列の列、複数の`let`宣言は`,`で区切ります。
- `exit`は入力の終端を表す特別なキーワードです。

### リテラルとデータ型

| 種類 | 例 | 備考 |
|---|---|---|
| 整数 | `123`, `0b1010`, `0xFF` | 多倍長整数 |
| 浮動小数点数 | `1.25`, `1.2e-3` | 多倍長浮動小数点数 |
| 複素数 | `2i`, `1 + 2i` | `i`を虚部に付けます |
| 真偽値 | `true`, `false` | 条件式で使用できます |
| 文字列 | `'hello'`, `"hello\n"` | `\n`、`\t`などのエスケープに対応 |
| 行列 | `[1, 2; 3, 4]` | `,`が列、`;`が行の区切り |
| 範囲 | `1..5`, `1..=5` | 整数の範囲 |
| 関数オブジェクト | `(x) { x * 2 }` | ラムダ式 |

ベクトルは独立した型ではなく、行列の一形態として扱われます。`[1, 2, 3]`は行ベクトル、`\vector(3)`は列ベクトルです。`void`や参照型が評価結果として現れることもありますが、これらはリテラルとして直接記述するものではありません。

### 変数宣言・代入・スコープ

```cpt
let x = 10, y = 20;
x := x + y;
x
```

- `let x = expr`または`let x := expr`で変数を宣言します。
- `let x = ..., y = ...`のように複数の変数をまとめて宣言できます。
- 既存の変数や参照先への代入には`:=`を使います。
- `=`と`==`は比較演算子として使えます。`=`は`let`の初期化にも使えます。
- 変数は関数・ラムダ・ブロック単位でスコープ管理されます。
- 関数名の重複や、予約語と同じ名前の変数・関数は定義できません。

### 制御構文

#### if式

条件は括弧で囲みます。分岐の本体は式でもブロックでも記述できます。

```cpt
let message = if (1 < 2) {
  "yes"
} else {
  "no"
};
message
```

#### while式

```cpt
let i = 0;
let total = 0;
while (i < 5) {
  total := total + i;
  i := i + 1;
};
total
```

#### for式

`for`は範囲または行列を反復します。

```cpt
let total = 0;
for i in 1..=5 {
  total := total + i;
};
total
```

`1..5`は終端の`5`を含まない半開区間、`1..=5`は終端を含む閉区間です。

### 関数・ラムダ式

```cpt
def square(x) {
  x * x
}

let double = (x) { x * 2 };
\print(square(5), double(5));
```

ユーザー定義関数は再帰できます。ラムダ式は変数に保存したり、関数の引数として渡したりできます。ラムダ式を作成した時点で、外側のスコープにある変数を参照します。

関数呼び出しの前にべき乗を置く記法もあります。

```cpt
def add1(x) { x + 1 }
add1^3(2)  # add1(2)の結果を3乗
```

## 演算子

高い優先順位から概ね次の順で評価されます。

1. 添字`A[i]`、後置階乗`x!`
2. 前置演算子`!x`、`-x`
3. べき乗`^`、`**`
4. 乗除`*`、`/`、`//`、`%`
5. 加減`+`、`-`
6. 範囲`..`、`..=`
7. 比較`<`、`<=`、`>`、`>=`、`=`、`==`、`!=`
8. 論理AND`&`、`&&`
9. 論理OR`||`
10. パイプライン`|`
11. 三項演算`? :`
12. 代入`:=`

べき乗と代入は右結合です。比較演算子は連鎖でき、`1 < x < 10`のように書けます。`&`／`&&`と`||`は短絡評価されます。

単独の`|`は論理演算子ではなく、パイプライン演算子です。式の隣接による省略乗算にも対応しているため、`2\pi`や`n f(n - 1)`のように書けます。単項マイナスとべき乗の結合が曖昧になる場合は、`-(2^2)`や`(-2)^2`のように括弧を付けてください。

### 数値演算の補足

- `/`は通常の除算です。整数同士でも割り切れない場合は浮動小数点数になります。
- `//`は切り捨て除算です。
- `^`／`**`は整数・浮動小数点数・複素数に使用できます。
- 階乗は0以上の整数に対してのみ定義されます。
- `%`は整数、または行列を左辺・スカラーを右辺とする組み合わせに対して使用できます。
- 真偽値は数値演算では必要に応じて数値として扱われます。

### LaTeX風の特殊記法

```cpt
\sum_{i=1}^{n} i
\prod_{i=1}^{n} i
\argmin_{i=1}^{n} i
\argmax_{i=1}^{n} i
\log_{2}(8)
```

- `\sum`と`\prod`は、下付きでループ変数と初期値、上付きで上限を指定します。
- `\argmin`と`\argmax`は、式の値を最小・最大にするループ変数の値を返します。
- `\log(x)`は自然対数、`\log_{b}(x)`は底を指定した対数です。

### 行列・添字・スライス

```cpt
let A = [1, 2; 3, 4];

\print(A * A);       # 行列積
\print(\dot(A, A));  # 要素ごとの積
\print(A[0][1]);     # 0始まりの添字

A[0][1] := 10;
\print(A);
```

- 行列同士の`+`と`-`は同じサイズで計算します。
- 行列同士の`*`は行列積です。スカラーとの演算は要素ごとに適用されます。
- `\dot(A, B)`は同じサイズの行列に対する要素積です。
- `A^{-1}`は正方行列の逆行列を計算します。行列の負のべき乗は`-1`以外は使用できません。
- `A[i]`は行列の行、`A[i][j]`は要素を参照します。添字は0始まりです。
- 範囲添字によるスライスが利用できます。`..`は終端を含まず、`..=`は終端を含みます。
- 添字やスライスの結果は参照として代入できる場合があります。

```cpt
let B = [1, 2, 3; 4, 5, 6; 7, 8, 9];
let S = B[0..2][1..3];
S[0..2][0..2] := 99;
\print(B);
```

### 範囲・パイプライン

パイプラインは左辺の値を、右辺の関数または組み込みアダプタの第1引数として渡します。

```cpt
let result =
  1..=10
  | \filter((n) { n % 2 == 0 })
  | \transform((n) { n * 10 });

\print(result);
```

利用できるアダプタは`\take`、`\drop`、`\filter`、`\transform`、`\enumerate`、`\reverse`です。これらは現在、結果を新しい行ベクトルとして評価します。

行列を反復すると、通常は行列なら行単位、行ベクトルや列ベクトルなら要素単位になります。`\as_mat(A)`を使うと、ベクトルも行列の行として反復できます。

## 組み込み定数

| 定数 | 意味 |
|---|---|
| `\pi` | 円周率 |
| `\e` | 自然対数の底 |
| `\i` | 虚数単位 |
| `\inf` | 正の無限大 |
| `\nan` | 非数（NaN） |
| `\eps` | 多倍長浮動小数点数のマシンイプシロン |
| `true` | 真 |
| `false` | 偽 |

```cpt
\print(\pi, \e, \i * \i, true, false);
```

## 組み込み関数

組み込み関数の名前は、ユーザー定義関数と区別するために`\`で始まります。引数の型やエラー条件を含む詳細仕様は[組み込み関数仕様](doc/spec/functions.md)を参照してください。

### 入出力

- `\print(expr, ...)`：引数を表示し、表示した個数を返します。
- `\read()`、`\input()`：標準入力から空行を除く1行を読みます。数値として解釈できる行は整数または浮動小数点数、それ以外は文字列になります。

### 数値・数学

- 絶対値：`\abs(x)`
- 対数・指数：`\log(x)`、`\log_{b}(x)`、`\log10(x)`、`\ln(x)`、`\lg(x)`、`\lb(x)`、`\exp(x)`
- 三角関数：`\sin(x)`、`\cos(x)`、`\tan(x)`、`\sec(x)`、`\csc(x)`、`\cot(x)`
- 逆三角関数：`\asin(x)`／`\arcsin(x)`、`\acos(x)`／`\arccos(x)`、`\atan(x)`／`\arctan(x)`
- 双曲線関数：`\sinh(x)`、`\cosh(x)`、`\tanh(x)`
- 丸め：`\ceil(x)`、`\floor(x)`、`\round(x)`、`\trunc(x)`
- 集約：`\min(x, ...)`、`\max(x, ...)`

```cpt
\print(\log(10), \log_{2}(8), \sin(\pi / 2));
\print(\min(3, 1, 4), \max(3, 1, 4));
```

### 累積計算

- `\sum_{i=start}^{end} expr`：範囲内の値を加算します。
- `\prod_{i=start}^{end} expr`：範囲内の値を乗算します。
- `\argmin_{i=start}^{end} expr`：式を最小にする`i`を返します。
- `\argmax_{i=start}^{end} expr`：式を最大にする`i`を返します。

### 線形代数・行列

- `\T(A)`：転置行列
- `\t(A)`：複素共役転置行列
- `\dot(A, B)`：要素積
- `\vector(n)`：`n`要素の列ベクトルを0で初期化
- `\rowvector(n)`：`n`要素の行ベクトルを0で初期化
- `\rows(A)`、`\cols(A)`：行数・列数
- `\as_mat(A)`：反復時に行列として扱うコピーを作成
- `\copy(A)`：行列などのディープコピー
- `\copy(v, range)`：ベクトルの範囲コピー
- `\copy(A, row_range, col_range)`：行列の範囲コピー
- `\ref(x)`：変数または行列要素への参照を作成

```cpt
let v = \rowvector(3);
v[0] := 10;
\print(v, \rows(v), \cols(v));
```

### 範囲アダプタ

範囲や行列を左辺に置き、パイプラインで呼び出します。

- `xs | \take(k)`：先頭から`k`個
- `xs | \drop(k)`：先頭から`k`個をスキップ
- `xs | \filter(pred)`：`pred`が真になる要素
- `xs | \transform(fn)`：各要素を変換
- `xs | \enumerate()`：インデックスと要素の組
- `xs | \reverse()`：順序を反転

## モジュール管理

```cpt
import "math_lib.cpt" as m;
\print(m::pi);
\print(m::square(5));
```

インポートした変数・関数は`alias::name`の形式で参照します。ファイルパスは実行時のカレントディレクトリを基準に解決されます。

## 型・演算に関する注意

- 未定義の変数・関数は評価時エラーになります。
- 行列演算では、演算に応じたサイズの一致が必要です。
- 複素数の大小比較は定義されていません。
- 浮動小数点数・複素数の剰余演算は定義されていません。
- 行列の添字やスライス範囲に負数は指定できません。
- 階乗は0以上の整数に対してのみ使用できます。
- 関数定義は関数内部では行えません。
- `-f`とコマンドライン上の数式は同時に指定できません。
